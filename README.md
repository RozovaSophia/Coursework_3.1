# 🎯 Анализ вакансий с HH.ru

Проект на Python для сбора данных о вакансиях с API HH.ru, их сохранения в базу данных и проведения анализа.

## 📋 Описание проекта

Этот проект позволяет:
- Получать данные о компаниях и вакансиях через API HH.ru
- Сохранять данные в реляционную базу данных
- Анализировать собранные данные с помощью различных методов
- Получать статистику по вакансиям и зарплатам
